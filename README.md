# Espelhamento de tela — Galaxy A12 para SEMP Roku

Aplicativo auxiliar para iniciar o espelhamento nativo do Android/Samsung na TV Roku.

## Uso
1. Coloque o Galaxy A12 e a TV na mesma rede Wi‑Fi.
2. Abra o app e toque em **Transmitir para Roku**.
3. Selecione a TV SEMP Roku na lista de dispositivos.
4. Aceite a solicitação de espelhamento na TV.

O APK usa o sistema de transmissão do Android. Isso é necessário porque a Roku recebe a tela por espelhamento compatível/Miracast; um servidor HTTP dentro do aplicativo não seria aceito pela TV.

## Compatibilidade
Testado como alvo para Android 12 e para a TV SEMP 43R6610 com Roku OS 15.3. A disponibilidade do dispositivo na lista depende de o espelhamento estar habilitado na TV e do suporte do firmware.
